# 002-Good-Sleep

一款專注於睡前預防、溫和引導與晨間正向復盤的原生 iOS 應用程式。針對現代人失眠的真實痛點，在睡前透過極簡、OLED 深色低刺激的介面，引導建立放鬆儀式與避坑檢核，並於醒來時提供晨間報告與自評記錄，打破「越想睡越睡不著」的焦慮惡性循環。

---

## MVP

### 核心痛點
- 又失眠了。睡覺超級重要，一失眠就會感受到狀態變差，不管是臉色暗沈、冒痘痘、眼睛酸、頭腦昏沈反應變慢等等。
- 失眠的原因有很多種，在失眠的時候才來想如何入睡基本上只是更加無法入睡，需要事前預防與低認知負擔的儀式引導。

### MVP 核心功能清單
- [ ] 睡眠建議（時刻檢視自己哪些沒有做好）
- [ ] 數據顯示
  - [ ] 入睡 / 起床時間
  - [ ] 睡眠時長
  - [ ] 晨間報告
- [ ] 智慧鬧鐘
  - [ ] 循環鬧鐘，也可隨時調整
  - [ ] 自動進入勿擾（系統勿擾導引與專注模式提示）
  - [ ] 入睡提醒
- [ ] 睡眠檢測評分
  - [ ] 睡眠日記（用戶起床可以自行記錄）
  - [ ] 自評 (狀態貼圖)
  - [ ] 是否賴床

## 🛠️ 技術路線
- **作業系統**：iOS 18+
- **開發語言**：Swift 6
- **UI 框架**：SwiftUI
- **建置工具**：Xcode 16
- **資料儲存**：SwiftData / AppStorage
- **系統框架**：UserNotifications (入睡提醒與鬧鐘), AVFoundation (微音效/鬧鈴), HealthKit (健康睡眠資料整合)

## 💡 使用說明
1. **睡前避坑與儀式檢核**：入夜後檢視今日作息（是否在傍晚後攝取咖啡因、睡前是否調暗環境燈光、遠離藍光刺激）。
2. **入睡提醒與智慧鬧鐘**：接收就寢排程提醒，設定溫和循環鬧鐘，並啟動夜間勿擾專注狀態。
3. **晨間報告與復盤自評**：醒來關閉鬧鐘後，記錄今日起床狀態貼圖、紀錄是否有賴床行為，並可隨手記下做夢或醒來當下的身體感受。

## 應用架構
- **純原生架構 (Pure Native iOS)**：基於 SwiftUI 聲明式介面與 Swift 現代並行 (Swift Concurrency)。
- **本機優先 (Local-First)**：使用 SwiftData 進行本機資料持久化，保護個人睡眠隱私。
- **低刺激視覺規範**：採用高對比低亮度之 OLED 深藍黑深夜護眼主題，全面降低夜間螢幕對褪黑激素的干擾。
