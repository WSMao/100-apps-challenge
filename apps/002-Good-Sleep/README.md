# 002-Good-Sleep

一款專注於睡前預防、溫和引導與晨間覆盤的 iOS 應用程式。針對現代人失眠的痛點，在睡前透過極簡深色低刺激的介面，引導建立放鬆儀式，並於醒來時提供晨間報告與自評記錄，藉由盤點記錄，注意自己的作息一步步調整，改善「想睡卻睡不著、睡不好」的惡性循環。

---

## MVP

### 核心痛點
- 又失眠了。睡覺超級重要，一失眠就會感受到狀態變差，不管是臉色暗沈、冒痘痘、眼睛酸、頭腦昏沈反應變慢等等。
- 失眠的原因有很多種，在失眠的時候才來想如何入睡基本上只是更加無法入睡，需要事前預防與低認知負擔的儀式引導。

### MVP 核心功能清單
- [x] 睡眠建議（時刻檢視自己哪些沒有做好：避坑防範、環境調節、放鬆靜心）
- [x] 數據顯示
  - [x] 入睡 / 起床時間紀錄
  - [x] 睡眠時長與 90 分鐘睡眠週期計算
  - [x] 今日晨間報告摘要卡片
- [x] 智慧鬧鐘
  - [x] 循環鬧鐘，也可隨時微調
  - [x] 5 款純原生 DSP 合成舒緩喚醒鈴聲（晨曦微光木琴、頌缽冥想鐘聲、森林晨鳥與溪流、柔和暖陽馬林巴、水晶音樂盒）與無縫無限重複播放 (`AVAudioPlayer.numberOfLoops = -1`)
  - [x] 支援使用者從 iOS「檔案 (Files) / iCloud Drive」匯入自訂音樂（`.mp3`, `.m4a`, `.wav`, `.caf`, `.aiff`, `.flac`），自動截取 28 秒並正規化轉檔為 Apple 原生 `.caf` 寫入 `Library/Sounds/`，同時相容前景循環與背景 `AlarmKit` / `UNNotificationSound`
  - [x] 15 秒漸進式溫和喚醒 (Gentle Fade-in：音量由 8% 平滑爬升至 100%)
  - [x] 自動進入勿擾（iOS 專注模式連動導引與提示）
  - [x] 入睡就寢排程提醒推播
- [x] 睡眠檢測評分
  - [x] 起床狀態自評貼圖 (🤩 精力充沛 / 😊 感覺良好 / 🥱 略帶倦意 / 😵 昏沈熊貓眼)
  - [x] 是否賴床檢測（記錄響鈴到實際起床時間差）
  - [x] 晨間微筆記（起床隨手記錄做夢或身心感受）
- [x] 助眠微音效（雨夜窗台、寧靜潮汐、深山晚風、溫柔白噪即時合成聲景）

## 💡 使用者應用指南
1. **今日儀表板 (Today)**：首頁呈現今晚目標就寢倒數、預計睡眠時長，醒來後第一時間呈現晨間報告或打卡入口。
2. **全螢幕睡覺貓頭鷹待機畫面 (Sleep Standby)**：按下「開始睡眠」後自動進入 OLED 暗夜貓頭鷹睡眠待機畫面，上方顯示鬧鐘時間與「倒數 XX:XX」起床倒計時，中央呈現 4-4 助眠深呼吸節奏的熟睡貓頭鷹動畫；輕觸貓頭鷹可觸發耳羽晃動微互動並展開「引導睡眠」、「即時紀錄」、「早起打卡」、「長按取消」四合一選單。內建 **5 分鐘無觸控自動調暗計時功能**，連續 5 分鐘無觸控即自動將螢幕調至最暗護眼狀態，點擊觸控螢幕任意處即恢復原本亮度。
3. **晨間鬧鐘睡醒伸懶腰貓頭鷹與起床打卡 (Wake-Up & Slide to Stop)**：
   - **鎖屏時**：透過 iOS 系統 `AlarmKit` 突破靜音與勿擾模式響鈴，並同步於鎖屏發送「起床打卡通知」；滑動停止系統鬧鐘後，可直接點選鎖屏通知進入 App 打卡。
   - **App 內**：顯示「貓頭鷹睡醒伸懶腰」幾何動畫 (`WakingOwlView`)，搭配「滑動來停止」互動滑桿；停止鬧鐘後進入起床確認畫面，提供【起床打卡】（直接開啟「編輯睡眠記錄」畫面紀錄昨晚睡眠）與【略過】2 個按鈕。
4. **睡前避坑與引導 (Checklist)**：確認下午不攝取咖啡因、睡前遠離螢幕、調暗環境光線，可一鍵開啟雨夜/潮汐白噪音放鬆入眠。
5. **智慧鬧鐘與自訂鈴聲庫 (Alarm)**：設定滾輪式就寢與起床時間，自動換算符合人體生理學之 90 分鐘睡眠週期數；可於「鬧鐘鈴聲」選擇 5 款內建舒緩鈴聲、開啟 15 秒漸進式溫和喚醒，或從 iOS「檔案」App 匯入個人喜愛的音樂（自動轉為 `.caf` 無縫循環鈴聲）。
6. **睡眠趨勢與歷史 (History)**：圖表化呈現平均睡眠時長、平均睡眠健康評分、賴床頻率與歷史紀錄列表。

### 鬧鐘響零與互動行為
1. 鎖屏（全屏 AlarmKit）
   - **按下稍後提醒（貪睡）**： 倒數計時，時間到會再次觸發鬧鐘
   - **按下關閉**： 跳出一般通知 → 點擊進入「早安畫面」
   - **按下實體按鍵（音量、電源）**： 關閉鬧鐘
2. 非鎖屏，在本 App 畫面中（通知型 Alarmkit，App 內建 Alarm 畫面，一般通知）
   - **按下稍後提醒（貪睡）**： 倒數計時，時間到會再次觸發鬧鐘
   - **按下關閉**： 直接由「內建 Alarm 畫面」切換到「早安畫面」了
   - **按下實體按鍵（音量、電源）**： 
3. 非鎖屏，其他畫面中（通知型 Alarmkit，一般通知）
   - **按下稍後提醒（貪睡）**： 倒數計時，時間到會再次觸發鬧鐘
   - **按下關閉**： 點選通知型 Alarmkit 或 一併出現的一般通知 → 點擊進入「早安畫面」
   - **按下實體按鍵（音量、電源）**：

## 應用架構與設計
- **純原生架構 (Pure Native iOS)**：基於 SwiftUI 聲明式介面與 `@MainActor` 單向資料流。
- **本機優先 (Local-First)**：所有資料均在本機持久化，完全保護個人隱私，免聯網、無外部伺服器依賴。
- **低刺激視覺規範**：採用高對比低亮度之 OLED 深藍黑深夜護眼主題，全面降低夜間螢幕對褪黑激素的干擾。

### AlarmKit
是程式突破鎖屏的方法。鎖屏時，透過 Alarmkit 設定鬧鐘，可產生如原生鬧鐘一樣的畫面與效果。可惜的是，實體按鍵預設對應到 stop，且 alarmkit 沒有選項可以調整，因此按實體鬧鐘時，其行為是「關閉鬧鐘」，不管有沒有設定「稍後提醒」，這點比較困擾一些，但應該習慣後就好了。

### 🦉 貓頭鷹動畫
- **純原生 SwiftUI 向量繪製**：全面採用 SwiftUI 原生 `Path`、`Shape` 與幾何曲線刻畫角色外型（`SleepingOwlView` 與 `WakingOwlView`），完全無需載入龐大的外部 Lottie、GIF 或序列圖檔，極大幅度降低安裝包體積與記憶體開銷。
- **狀態插補與生動模擬**：充分發揮 SwiftUI 宣告式動畫的威力，透過狀態（State）變數的變化，由底層動畫引擎自動進行前後狀態的平滑數值插補（Interpolation）。這項技術不僅能實現基礎的互動效果，更能精確模擬出生動鮮活的有機動態——從夜間睡眠時胸口緩慢起伏的呼吸律動、眨眼微表情，到晨間被喚醒時伸懶腰打哈欠的伸展身姿，皆栩栩如生。

### 🎵 聲音合成 (Audio DSP)
內建音源採用數位訊號處理（DSP），無需任何預先錄製的外部音檔。

#### 睡眠引導的白噪音：
- **即時數位訊號合成 (DSP)**：透過數學公式與諧波疊加運算生成雙聲道 PCM WAV 與 CAF 音訊，於啟動系統時即時合成，不佔用 App 預先打包容量。
- **自然過渡**：具備 2 秒等功率平滑交叉淡入淡出（Crossfade），消除循環邊界爆音，實現完全無縫的無限循環沈浸體驗。

#### 內建舒緩晨鈴：
- **iOS 檔案沙盒規範**：受限於 iOS 系統級通知與 AlarmKit 的沙盒限制，鎖屏喚醒鈴聲無法任意讀取 Documents 或暫存目錄，必須存放於 App 專屬的 `Library/Sounds/` 目錄中，且音訊格式須為 Apple 原生的 Core Audio 格式（`.caf`）。
- App 透過 `RingtoneLibraryManager`，在首次啟動時由演算法即時合成 4 款高品質 `.caf` 鈴聲並自動寫入 `Library/Sounds/` 目錄。
- 採用「自然正弦泛音」與「包絡衰減」演算法，重複播放自然過渡，帶來溫柔舒緩的喚醒體驗。

#### 使用者匯入鈴聲：
使用者也可以自行匯入鈴聲，系統將自動裁剪並轉換為 `.caf`。
