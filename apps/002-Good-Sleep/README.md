# 002-Good-Sleep

一款專注於睡前預防、溫和引導與晨間覆盤的 iOS 應用程式。針對現代人失眠的痛點，在睡前透過極簡深色低刺激的介面，引導建立放鬆儀式，並於醒來時提供晨間報告與自評記錄，藉由盤點記錄，注意自己的作息一步步調整，改善「想睡卻睡不著、睡不好」的惡性循環。

---

## MVP

### 核心痛點
- 又失眠了。睡覺超級重要，一失眠就會感受到狀態變差，不管是臉色暗沈、冒痘痘、眼睛酸、頭腦昏沈反應變慢等等。
- 失眠的原因有很多種，在失眠的時候才來想如何入睡基本上只是更加無法入睡，需要事前預防與低認知負擔的儀式引導。

### MVP 核心功能清單
- [x] 引導睡眠
  - [x] 白噪音與冥想引導
  - [x] 好睡清單，幫助使用者檢查是否做好睡眠準備
  - [x] 科學入睡，提供專題研究報告，了解睡眠是怎麼一回事
- [x] 智慧鬧鐘
  - [x] 制定睡眠目標：睡眠時長、目標就寢時間及喚醒時間。也可完全關閉鬧鐘，睡到自然醒來再記錄，藉此找到自己適合的睡眠時長。
  - [x] 循環鬧鐘、稍後提醒、就寢前提醒
  - [x] 內建 DSP 合成舒緩喚醒鈴聲，也支援使用者匯入自訂音樂
  - [x] 15 秒漸進式溫和喚醒 
- [x] 數據紀錄
  - [x] 入睡 / 起床時間、睡眠時長記錄
  - [x] 睡前、晨醒筆記（起床隨手記錄做夢或身心感受）
  - [x] 起床狀態自評貼圖 (🤩 精力充沛 / 😊 感覺良好 / 🥱 略帶倦意 / 😵 昏沈熊貓眼)、是否賴床

## 💡 使用者應用指南
### 分頁介紹
1. **第一個分頁（Today 儀表板）**：
   - 呈現今晚睡眠目標，點擊【晚安】以記錄睡前筆記，再點擊【開始睡眠】即可入睡。
   - 也包含前一晚的睡眠報告。
2. **第二個分頁（引導睡眠）**：提供好眠的科學文章、檢核清單以及白噪音及冥想引導睡眠。
3. **第三個分頁（制訂睡眠計畫、設定智慧鬧鐘）**：
   - 使用內建鬧鐘或匯入自己的鬧鈴，漸進式溫和喚醒。
   - 有「稍後提醒」功能，但需注意：當鬧鐘響起時，iPhone 的側邊實體按鍵會直接關閉鬧鐘，此與系統內建的鬧鐘使用習慣不同（這部分為 AlarmKit 限制）。
4. **第四個分頁（歷史紀錄）**：顯示歷史紀錄列表。日曆左上角圖示彈窗查看睡眠統計（平均時長、4 種自評身心狀態佔比、熬夜率、賴床率）。

### 全螢幕睡覺貓頭鷹待機畫面 (Sleep Standby)
按下「開始睡眠」後自動進入貓頭鷹睡眠待機畫面。輕觸貓頭鷹可展開「引導睡眠」、「即時紀錄」、「起床打卡」、「長按取消」選單。連續 5 分鐘無觸控即自動將螢幕調至最暗護眼狀態（點擊螢幕恢復），待 iPhone 鎖屏時間觸發鎖屏。

### 鬧鐘響零與互動行為

1. 鎖屏（全屏 AlarmKit）：透過 iOS 系統 `AlarmKit` 突破靜音與勿擾模式響鈴，滑動停止系統鬧鐘後，可直接點選鎖屏「起床打卡通知」進入 App 內「早安打卡畫面」。
   - **按下「稍後提醒」**： 貪睡倒數計時
   - **「滑動來停止」**： 關閉鬧鐘
   - **按下實體按鍵（音量、電源）**： ==會徹底關閉鬧鐘==
2. 非鎖屏，在本 App 畫面中（通知型 Alarmkit 加上 App 內建 Alarm 畫面）
   - **按下「稍後提醒」或 AlarmKit 通知的「貪睡」按鈕**： 貪睡倒數計時
   - **Alarm 畫面「滑動來停止」或按下通知型 AlarmKit 「關閉」按鈕**： 關閉鬧鐘，進入「早安打卡畫面」
   - **按下實體按鍵（音量、電源）**： 僅關閉聲音
3. 非鎖屏，其他畫面中（通知型 Alarmkit，一般通知）
   - **AlarmKit 通知的「貪睡」按鈕**： 貪睡倒數計時
   - **按下通知型 AlarmKit 「關閉」按鈕**： 關閉鬧鐘，點選通知型 Alarmkit 或 一併出現的一般通知，進入 App 內「早安打卡畫面」
   - **按下實體按鍵（音量、電源）**： 僅關閉聲音

停止鬧鐘後進入「早安打卡畫面」，提供【起床打卡】（開啟「編輯睡眠記錄」畫面）與【略過】2 個按鈕。

## 🚀  開發者安裝說明

1. 確保已安裝 macOS 與 Xcode 16+
2. 開啟本專案目錄中的 Xcode 專案檔

```bash
open apps/002-Good-Sleep/GoodSleep.xcodeproj
```

3. 於 Xcode 目標選擇模擬器（如 iPhone 16 Pro）或實體 iPhone
4. 按下 Cmd + R 進行建置與執行

亦可透過終端機進行命令列編譯驗證：
```bash

  -project apps/002-Good-Sleep/GoodSleep.xcodeproj \
  -scheme GoodSleep \
  -destination "generic/platform=iOS Simulator" \
  CODE_SIGNING_ALLOWED=NO build
```

## 應用架構與設計
- **純原生架構 (Pure Native iOS)**：基於 SwiftUI 聲明式介面與 `@MainActor` 單向資料流。
- **本機優先 (Local-First)**：所有資料均在本機持久化，完全保護個人隱私，免聯網、無外部伺服器依賴。
- **低刺激視覺規範**：採用高對比低亮度深藍黑深夜護眼主題，全面降低夜間螢幕對褪黑激素的干擾。

### AlarmKit
是程式突破鎖屏的方法。鎖屏時，透過 Alarmkit 設定鬧鐘，可產生如原生鬧鐘一樣的畫面與效果。可惜的是，實體按鍵預設對應到 stop，且 alarmkit 沒有選項可以調整，因此按實體鬧鐘時，其行為是「關閉鬧鐘」，不管有沒有設定「稍後提醒」，這點比較困擾一些，但應該習慣後就好了。

### 🦉 貓頭鷹動畫
- **純原生 SwiftUI 向量繪製**：全面採用 SwiftUI 原生 `Path`、`Shape` 與幾何曲線刻畫角色外型（`SleepingOwlView` 與 `WakingOwlView`），完全無需載入龐大的外部 Lottie、GIF 或序列圖檔，極大幅度降低安裝包體積與記憶體開銷。
- **狀態插補與生動模擬**：充分發揮 SwiftUI 宣告式動畫的威力，透過狀態（State）變數的變化，由底層動畫引擎自動進行前後狀態的平滑數值插補（Interpolation）。這項技術不僅能實現基礎的互動效果，更能精確模擬出生動鮮活的有機動態——從夜間睡眠時胸口緩慢起伏的呼吸律動、眨眼微表情，到晨間被喚醒時伸懶腰打哈欠的伸展身姿，皆栩栩如生。

### 🎵 聲音合成 (Audio DSP)
內建音源採用數位訊號處理（DSP），無需任何預先錄製的外部音檔。

#### 睡眠引導的白噪音：
- **即時數位訊號合成 (DSP)**：透過數學公式與諧波疊加運算生成雙聲道 PCM WAV 與 CAF 音訊，於啟動系統時即時合成，不佔用 App 預先打包容量。
- **自然過渡**：具備 2 秒等功率平滑交叉淡入淡出（Crossfade），消除循環邊界爆音，實現完全無縫的無限循環沈浸體驗。

#### 內建舒緩晨鈴：
- **iOS 檔案沙盒規範**：受限於 iOS 系統級通知與 AlarmKit 的沙盒限制，鎖屏喚醒鈴聲無法任意讀取 Documents 或暫存目錄，必須存放於 App 專屬的 `Library/Sounds/` 目錄中，且音訊格式須為 Apple 原生的 Core Audio 格式（`.caf`）。
- App 透過 `RingtoneLibraryManager`，在首次啟動時由演算法即時合成 4 款高品質 `.caf` 鈴聲並自動寫入 `Library/Sounds/` 目錄。
- 採用「自然正弦泛音」與「包絡衰減」演算法，重複播放自然過渡，帶來溫柔舒緩的喚醒體驗。

#### 使用者匯入鈴聲：
使用者也可以自行匯入鈴聲，系統將自動裁剪並轉換為 `.caf`。
