# Creative-Neuro (003) — Phase 1 互動白板與心智圖核心規格 PRD

---

## Problem Statement

視覺化思考工作者在整理想法與系統架構時，往往需要在「心智圖工具（快速鍵盤發想）」、「流程圖工具（自動排版與語法同步）」與「自由白板（無邊界構圖與手繪）」之間反覆切換。現有單一工具通常有以下痛點：

1. **操作流中斷**：缺乏類似 Xmind 的直覺鍵盤發想（`Tab` / `Enter` / 方向鍵）與雙擊建立、懸停拉線等低阻力手勢，或是手勢與畫布框選、平移相互衝突。
2. **選取與編輯干擾**：多選框選時常誤選邊界物件或觸發無限渲染崩潰；浮動工具列容易被其他節點或連線遮擋；文字節點預設帶有厚重背景框，干擾純文字筆記視覺。
3. **連線與佈局缺乏彈性**：連線端點與幾何樣式（跳線、折線、曲線、直線）切換繁瑣，手動調整與自動排版（Auto-ELK）難以並存。
4. **復原／重做不可靠**：拖曳過程產生大量碎裂歷史步驟、切換分頁或 DOM 自動測量意外清空 Redo 堆疊，或跨專案切換造成歷史狀態污染。

---

## Vision

1. 以 Miro 以及 XMind 為標竿，打造全方位圖形發想平台。透過自由無限的白板，隨意使用心智圖、流程圖或手繪。
2. 透過與 AI 交談，實時由 Agent 為您梳理出想法脈絡，共同協作激發創意。
3. 可分享內容，以高品質的圖片匯出或提供連結的方式嵌入到其他內容顯示平台。

## User Stories

### 一、操作與互動 (Operations & Interactions)

1. [ ] As a 畫布使用者, I want 在任何工具模式下用滑鼠右鍵拖移平移畫布、單擊右鍵則開啟應用專屬上下文選單並攔截瀏覽器原生選單, so that 我可以隨時快速移動視野或執行快捷操作而不被原生選單打斷。
2. [ ] As a 畫布使用者, I want 使用垂直滾輪上下捲動、`⇧ + 滾輪` 左右捲動、`⌘/Ctrl + 滾輪` 或觸控板雙指縮放畫布, so that 我能流暢地進行多維度畫布導覽。
3. [ ] As a 畫布使用者, I want 在空白處直接左鍵拖曳拉出矩形選取框（完整涵蓋模式 `SelectionMode.Full`，無需按住 Shift），且在快速框選時不會發生狀態乒乓循環或黑屏崩潰, so that 我能精準且穩定地框選目標物件。
4. [ ] As a 畫布使用者, I want 選中節點時看到清晰的高亮外框（如亮青藍 Ring/Outline）, so that 我能一眼辨識目前的選取焦點。
5. [ ] As a 畫布使用者, I want 滑鼠懸停在節點上時拖曳四周的「+」連接點拉出連線並吸附至目標節點, so that 我能不切換工具就快速建立節點關聯。
6. [ ] As a 畫布使用者, I want 在畫布空白處左鍵雙擊即時於滑鼠座標建立一個新的浮動節點, so that 我能隨時捕捉突發靈感。
7. [ ] As a 心智圖發想者, I want 系統記憶我最後一次使用 `⌥ + 方向鍵` 建立節點的方向，並讓後續按 `Tab`（子節點）與 `Enter`（兄弟節點）繼承該記憶方向, so that 我可以順著同一思維流向（上／下／左／右）連續展開樹狀結構。
8. [ ] As a 鍵盤重度使用者, I want 在選中單一節點時按方向鍵（`↑` / `↓` / `←` / `→`）將選取焦點跳轉至該方向空間距離最近的相鄰節點, so that 我能純靠鍵盤在畫布節點間遊走。
9. [ ] As a 畫布使用者, I want 右下角畫布控制列的放大（+）、縮小（-）與適應畫面（Fit View / Fullscreen）按鈕點擊皆能正常運作, so that 我可以透過滑鼠精確控制檢視比例。
10. [ ] As a 畫布使用者, I want 節點周圍的四個「+」連接點平時隱藏、僅在滑鼠懸停時顯現，且中心精確對齊節點水平與垂直中心線的幾何邊框交點, so that 畫布保持簡潔且拉線起點視覺對齊準確。
11. [ ] As a 畫布使用者, I want 左鍵矩形框選時，只有當連接線段（Edge）的 Source 與 Target 兩端節點皆完整落在選取框內才將該連線選中, so that 框選局部區域時不會誤選連往框外的線段。

### 二、專案與多工作區管理 (Project Management)

12. [ ] As a 思考工作者, I want 建立新專案並自動初始化預設 Board 與 Page（支援重複名稱警告與預設 `untitled` 自動遞增命名）, so that 我可以為不同主題開設獨立的思考空間。
13. [ ] As a 思考工作者, I want 在工作區清單中瀏覽所有已儲存於本地的專案，並支援一鍵切換、重新命名或刪除專案, so that 我能安全管理多個本機離線專案。

### 三、工具列功能 (Tools & Interaction Modes)

14. [ ] As a 流程圖繪製者, I want 在切換至 Connector 連線工具後依序點擊起點與終點節點即可自動建立連線，並可按 `Esc` 取消當前連線流程, so that 我能用點擊方式輕鬆串接節點。
15. [ ] As a 流程圖繪製者, I want Connector 工具自動從兩個節點各 4 個端點中挑選距離最近的一對端點進行連接，且完成後維持於 Connector 模式, so that 我能連續為多組節點建立視覺最合理的連線。
16. [ ] As a 流程圖繪製者, I want 點選並拖曳既有連接線的尾端重新指向其他節點, so that 我可以調整連線歸屬而無須刪除重畫。
17. [ ] As a 流程圖繪製者, I want 支援跳線（Jump Arc）、直角折線（Smoothstep）、平滑曲線（Bezier）與直線（Straight）四種連線幾何，並在單選或多選連線時於頂層顯示單一集中式快速選單，可批次變更線型（實線／虛線／點線）、箭頭樣式（單向／雙向／無）與刪除, so that 我能統一美化與調整大量連線。
18. [ ] As a 流程圖繪製者, I want 在左側 Connector 工具選單中選擇並記憶預設連線類型（`defaultEdgeRoutingType`）, so that 後續連續點擊連線或從節點把手拉線時皆自動套用我的偏好樣式。
19. [ ] As a 畫布使用者, I want 在選取工具（V）提供物件類別過濾選單（形狀、連線、文字、容器、Mermaid 圖表）搭配全選／取消全選按鈕與過濾狀態提示圓點，且所有工具列彈出選單在點擊外部區域時自動收起, so that 在複雜畫布上能只選取特定類型的物件而不被誤觸干擾。

### 四、介面佈局與風格外觀 (UI Layout & Theme System)

20. [ ] As a 畫布使用者, I want 畫布縮放控制項（放大、縮小、適應畫面）固定於畫布右下角, so that 視窗操作重心符合常見白板軟體習慣。
21. [ ] As a 畫布使用者, I want 快捷鍵與操作提示清單放置於畫布左下角, so that 需要查閱熱鍵時一目了然且不遮擋主畫布。
22. [ ] As a 應用使用者, I want 頂部導覽列右上角提供 Export 與 Settings 按鈕（設定彈窗保留 General 與 About 分頁），左上方雙腦半球圓形 Logo 下拉選單整合 New Project、Workspace（寬敞置頂視窗）、New Page 與多格式 Import Project（`.neuro.json` / `.neuro.svg` / `.neuro.png`），且下拉選單起始位置不遮擋左側工具列, so that 工作區導覽層次清晰、品牌辨識度高且不發生按鈕重疊。
23. [ ] As a 應用使用者, I want 系統預設採用亮色模式（Light Mode），並可在設定彈窗的 General 分頁即時切換亮色／暗色主題且自動持久化, so that 我能依環境光線選擇舒適的視覺外觀。
24. [ ] As a 畫布編輯者, I want 單選節點時於節點正上方顯示橫向快速選單（支援形狀切換、字級、對齊與色彩等），多選節點時則僅在包圍外框上方顯示單一集中式快速選單並支援批次套用（佈局模式、樣式、圖層、群組、刪除）, so that 編輯工具始終隨手可得且多選時畫面不凌亂。
25. [ ] As a 畫布編輯者, I want 無論單選或多選任何節點（Shape / Text / Frame / Diagram）或連線，其快速選單與選中節點外層容器皆強制位於絕對最頂層（`z-[99999]`）, so that 快速選單永遠完整可視，絕不被畫布上其他容器或節點遮擋。

### 五、進階編輯功能 (Core Advanced Features)

26. [ ] As a 架構圖繪製者, I want 透過節點快速選單或畫布控制，在 `auto-elk` 自動佈局與 `manual` 手動佈局模式之間一鍵切換, so that 我能同時享有自動排版的效率與手動微調的自由。
27. [ ] As a 畫布編輯者, I want 調整節點的圖層順序（移至頂層、移至底層、上移一層、下移一層）, so that 重疊物件的遮罩與層級關係符合預期。
28. [ ] As a 畫布編輯者, I want 透過 `⌘/Ctrl + 點擊` 或矩形框選同時選取多個節點，並在多選時顯示標註選取總數的包圍外框（具備非有限值與缺失座標防禦）, so that 我能清楚掌握多選範圍並避免幾何異常崩潰。
29. [ ] As a 畫布編輯者, I want 將多選物件透過 `⌘G` 或快速選單建立邏輯群組（以 `groupId` 關聯而非包成 Frame 容器），點擊群組任一物件即全選並支援同步拖移，且可用 `⌘⇧G` 解散群組, so that 多個關聯物件能像單一單元般移動而不改變原有層級結構。
30. [ ] As a 畫布筆記使用者, I want 文字節點（TextNode）預設無實體背景色（`transparent`）與無邊框，僅在選取或懸停時保留細緻高亮外框, so that 純文字標註能自然融入白板背景。

### 六、復原與重做保證 (Undo / Redo Reliability & Atomicity)

31. [ ] As a 畫布編輯者, I want 按 `Tab` 或 `Enter` 產生子／兄弟節點及其連線時視為單一原子交易, so that 按一次 `⌘Z` 就能同時移除節點與連線，按 `⌘⇧Z` 也能一併重做。
32. [ ] As a 畫布編輯者, I want 拖曳移動節點時暫停中間歷程紀錄、僅於拖曳結束時注入起點快照, so that 按一次 `⌘Z` 即可精確回到拖曳前座標而無需連續撤銷數十次。
33. [ ] As a 畫布編輯者, I want 切換 Page 分頁以及執行單選、多選、框選或選取連線時不產生歷史紀錄也不清除 Redo 堆疊, so that 檢視或選取動作不會破壞我原本的復原／重做脈絡。
34. [ ] As a 畫布編輯者, I want React Flow 的自動 DOM 尺寸測量（ResizeObserver）與 CodeMirror Mermaid 編輯器的雙向同步回音不會觸發歷程異動或清空 Redo 堆疊, so that 背景同步機制不會無故抹除歷史狀態。
35. [ ] As a 多專案使用者, I want 新建、切換或匯入專案時自動清空歷史紀錄，且批次刪除（`Delete` / `Backspace`）與自由手繪橡皮擦手勢皆以單次交易提交, so that 不同專案的歷史絕不互相污染，批次刪除與擦除也能一鍵完整復原。

## Implementation Decisions

- **狀態管理與切片分離**：將核心狀態拆分為「受 Zundo 歷程追蹤的持久化場景圖狀態（專案、畫板、分頁、節點、連線、當前分頁）」與「不進歷程的暫態 UI 狀態（工具模式、選取清單、懸停／編輯／拖曳旗標、選取過濾器、預設連線類型、主題模式）」。
- **選取與框選防護機制**：
  - 畫布框選採用完整涵蓋判定（`SelectionMode.Full`）並啟用無鍵直接拖曳框選；連線框選須驗證 Source 與 Target 兩端節點皆完整落於選取框內。
  - 選取同步採用 `isInternalSelectionRef` 與 Set Equality Guard（集合冪等性比對），阻斷雙向同步引發的無限重新渲染迴圈，並於畫布外層配置 ErrorBoundary 攔截例外與提供鍵盤／點擊復原。
- **歷程交易與隔離設計**：
  - 複合操作（方向性產生節點+連線、批次刪除、橡皮擦軌跡批次移除）必須包在單一 Store Action 內一次寫入，確保單步 Undo/Redo。
  - 拖曳手勢透過 `temporal.pause()` / `resume()` 與起點快照注入實現原子復原。
  - DOM 測量尺寸更新與 Mermaid 反向同步派發須標記忽略歷程或透過 Zundo `partialize` / `equality` 過濾，避免清除 Redo 堆疊。
  - 專案新建、切換、匯入時主動呼叫 `temporal.clear()` 隔離歷史。
- **幾何、佈局與碰撞避障引擎**：
  - 節點佈局採用三態模式（`auto-elk`、`manual`、`fixed`），`manual` 與 `fixed` 座標在 AST 同步與自動排版時必須保留。
  - 方向性衍生節點採用 AABB 碰撞偵測與 Minkowski 和外擴計算避開障礙物；四個「+」連接點中心對齊節點中心線邊框交點，消除 CSS transform 與 Tailwind translate 雙重偏移。
  - 邏輯群組採用節點上的 `groupId` 欄位實作，不建立額外 `FrameNode` 包裝層；圖層順序透過標準化 `zIndex` 操作。
- **選單層級與工具列收合**：
  - 所有浮動快速選單（單選節點、單選連線、多選節點集中選單、多選連線集中選單）及選中節點外層 DOM 容器均統一提升至最高層級（`z-[99999]`），確保不被其他畫布元素遮擋。
  - 工具列彈出子選單（選取過濾、形狀選擇、連線類型預設）統一掛載外部點擊偵聽自動收起。
- **本地持久化與多格式匯出**：
  - 透過 IndexedDB（Dexie）儲存完整專案資料與專案清單摘要，寫入採防抖機制；匯出／匯入支援 JSON、SVG、PNG（內嵌 zlib 壓縮專案資料）與 Mermaid DSL。

## Testing Decisions

- **測試原則**：所有測試僅驗證公開介面（Store Actions、純函數引擎 API、快捷鍵分派器、真實瀏覽器 DOM 行為）的可觀察輸出與狀態變化，不依賴私有欄位或原始碼字串比對；Mock 僅限外部邊界（如 IndexedDB 或瀏覽器視窗環境）。
- **分層測試策略與驗證邊界**：
  1. **核心演算法純函數測試（Engine Tests）**：驗證 Mermaid 解析／序列化／AST 對帳、ELK 混合佈局、AABB 碰撞避障、SVG 跳線交叉幾何與效能基準。
  2. **領域契約與狀態機測試（4-Tier Domain & Requirements Tests）**：涵蓋 Store 領域切片、方向性衍生、Zundo 原子 Undo/Redo、多專案生命週期、選取過濾與多邊形／多選邏輯（延續現有 4-Tier 測試架構與需求對應測試）。
  3. **元件與整合測試（Vitest）**：驗證特定元件互動、條件渲染與 Store 串接。
  4. **真實瀏覽器端對端測試（Headless Chrome CDP E2E）**：針對畫布右鍵拖移、左鍵框選無循環崩潰、文字輸入法（IME）、焦點競態、浮動選單頂層可視性與截圖回歸進行真機驗證，確保 Console 零錯誤。

## Out of Scope

依據目前 Phase 1 規格範圍，以下項目不包含在本文件實作與驗收範疇內（列於專案 Roadmap 供後續獨立立項）：

- **AI 即時語音共同繪圖**：Gemini Multimodal Live API（WebSocket / WebRTC + VAD + Function Calling）整合。
- **雲端儲存與多人即時協作**：遠端資料庫同步、多人游標協作與雲端互動式 Embed URL 分享。
- **桌面端原生封裝**：Tauri 2.0 macOS / Windows 桌面應用程式打包。
